# 🔔 Автоматичний дверний дзвінок / привітач для магазину чи кімнати (Arduino)

Проєкт автоматичного звукового сповіщувача на базі мікроконтролера **Arduino**, інфрачервоного датчика руху **PIR** та п'єзодинаміка (Buzzer). 

Пристрій реагує на наближення людини або вхід відвідувача до приміщення та програє коротку приємну мелодію-привітання.

---

## 🚀 Основні можливості

- 🎶 **Звукове сповіщення:** Програвання мелодії привітання за допомогою функції `tone()`.
- 👁️ **Автоматичне виявлення:** Безконтактне спрацювання завдяки ІЧ-датчику руху.
- ⏱️ **Захист від повторного спрацювання:** Налаштований таймаут після програвання мелодії, щоб дзвінок не лунав безперервно, поки людина стоїть поруч.
- ⚡ **Простота та автономність:** Легко збирається на будь-якій платі Arduino та може працювати від батарейки 9V або USB.

---

## 🛠️ Необхідні компоненти

- **Мікроконтролер:** Arduino (Nano / Uno / Pro Mini / Mega)
- **Датчик руху:** PIR HC-SR501 або мініатюрний AM312
- **Звуковий випромінювач:** Пасивний п'єзодинамік (Passive Buzzer) або звичайний маленький динамік 8 Ом (з резистором 100 Ом)
- **Джерело живлення:** 5V (USB, блок живлення) або акумулятор/батарея 9V "Крона" (через VIN)
- **Допоміжні деталі:** Сполучні дроти (Dupont), макетна плата

---

## 🔌 Схема підключення (Pinout)

| Компонент | Пін компонента | Пін Arduino | Примітка |
| :--- | :--- | :--- | :--- |
| **PIR Sensor** | VCC | **5V** | Живлення датчика |
| | GND | **GND** | Спільне заземлення |
| | OUT (Signal) | **Pin 2** | Цифровий вхід руху |
| **Buzzer (Динамік)** | (+) Позитивний | **Pin 8** | Цифровий/ШІМ вихід |
| | (-) Негативний | **GND** | Спільне заземлення |
